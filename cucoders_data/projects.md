## [Harry Potter Game](https://github.com/Jcyern/Harry_Potter_Game)

![Harry Potter Game](https://via.placeholder.com/800x400/2d2d2d/ffffff?text=Harry+Potter+Game+%7C+Unity+C%23)

## [Intérprete del lenguaje Wally](https://github.com/Jcyern/pixeleando-con-wally)

![Intérprete Wally](https://via.placeholder.com/800x400/2d2d2d/ffffff?text=Int%C3%A9rprete+Wally+%7C+Python)

**Descripción**: Intérprete para el lenguaje Wally, diseñado para dibujar figuras geométricas mediante comandos como `draw`, `move`, `set_color` y `repeat`. El proyecto incluye:

- Analizador léxico que tokeniza el código fuente.
- Analizador sintáctico que construye un AST.
- Entorno de ejecución que interpreta las instrucciones.
- Manejo de errores con mensajes descriptivos.

## [MINIX - Sistema Operativo](https://github.com/Jcyern/minix)

![MINIX](https://via.placeholder.com/800x400/2d2d2d/ffffff?text=MINIX+%7C+Sistemas+Operativos)

**Descripción**: Proyecto sobre el sistema operativo MINIX 3, realizado como parte de la asignatura de Sistemas Operativos. Incluye:

- Análisis y modificación del código fuente del núcleo.
- Implementación de cambios en el sistema de archivos o gestión de procesos.
- Uso de Git para fork y seguimiento de cambios sobre el repositorio oficial.
- Comprensión de la arquitectura de microkernel y comunicación entre servidores.
